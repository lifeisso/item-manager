要实现您提到的 --manual-auth-hook 方式的自动续期，核心思路是让 Certbot 在需要验证时，自动调用一个脚本来通过阿里云 API 添加和删除 DNS TXT 记录，从而将整个过程自动化。

下面是为您整理的具体操作指南。

1. 准备工作：安装阿里云 CLI 并配置凭证
这个脚本需要调用阿里云的 API，因此必须先安装 aliyun 命令行工具并配置好访问密钥。

安装 Aliyun CLI:

bash
# 下载并解压
wget https://aliyuncli.alicdn.com/aliyun-cli-linux-latest-amd64.tgz
tar xzvf aliyun-cli-linux-latest-amd64.tgz
# 移动到系统路径并赋予执行权限
sudo cp aliyun /usr/local/bin
rm aliyun
配置凭证:
运行以下命令，根据提示输入您的 AccessKey ID、Secret 和区域（如 cn-hangzhou）。

bash
aliyun configure
请确保您的 AccessKey 拥有 AliyunDNSFullAccess 权限。

2. 部署认证钩子脚本
--manual-auth-hook 需要一个可执行的脚本来完成 DNS 记录的增删。您可以参考社区方案创建一个脚本，例如 /usr/local/bin/alidns.sh。

下载或创建脚本:
您可以从justjavac/certbot-dns-aliyun项目获取一个现成的脚本。

bash
# 下载脚本并赋予执行权限
sudo wget -O /usr/local/bin/alidns.sh https://cdn.jsdelivr.net/gh/justjavac/certbot-dns-aliyun@main/alidns.sh
sudo chmod +x /usr/local/bin/alidns.sh
注意：该脚本 (alidns.sh) 的工作原理是在验证时调用 aliyun 工具添加记录，验证完成后删除记录。您需要确保脚本已正确安装并可执行。

3. 执行自动续期命令
当您完成了上述准备，就可以通过 certbot renew 命令来自动续期了。该命令会读取您首次申请证书时生成的配置，并应用您指定的钩子。

bash
sudo certbot renew \
  --manual \
  --preferred-challenges dns \
  --manual-auth-hook "alidns" \
  --manual-cleanup-hook "alidns clean" \
  --deploy-hook "nginx -s reload" \
  --dry-run
参数说明:

--manual-auth-hook "alidns": 指定在验证时运行 alidns.sh 脚本。

--manual-cleanup-hook "alidns clean": 验证成功后，运行脚本清理添加的 TXT 记录。

--deploy-hook "nginx -s reload": （重要） 在证书成功更新后，执行重载 Web 服务器配置的命令（这里以 Nginx 为例），让新证书生效。请根据您的实际情况修改此命令。

--dry-run: 强烈建议先加上这个参数进行测试。它会模拟整个流程，但不会真正颁发证书，可以避免触发速率限制。测试无误后，移除该参数执行真正的续期。

4. 设置定时任务，一劳永逸
为了完全自动化，您可以将上述命令（去掉 --dry-run）添加到系统的 crontab 定时任务中，例如每天运行一次。

bash
sudo crontab -e
# 添加以下行，每天凌晨 1 点 1 分执行
1 1 * * * root certbot renew --manual --preferred-challenges dns --manual-auth-hook "alidns" --manual-cleanup-hook "alidns clean" --deploy-hook "nginx -s reload"
提示：Certbot 的 renew 命令非常智能，它只会续期那些在到期前30天内需要续期的证书，因此您无需担心它会频繁操作
